# Multi-principal Sites canary

## Актуальная ручная приёмка

Все ручные проверки этой области выбираются из
[глубокого каталога по темам](manual-acceptance/uat-selection.md).
[Карта соответствия прежних проверок](manual-acceptance/uat-selection.md#карта-расширенных-источников)
показывает заменяющие ID. Шаги и результаты вести только по этим карточкам.

## Автоматизация и исторический строгий режим

[Исходный специализированный контракт](legacy-acceptance/uat-multi-principal-runbook.md) сохранён
отдельно: команды автоматического gate, setup/cleanup, schemas, receipts и
исторические матрицы. Использовать его для явно выбранного machine/strict gate,
не как второй ручной checklist. Код автоматизации этим переносом не меняется.
Устаревшие bindings/singleton/description assertions не определяют текущее
поведение продукта; требование старого gate с несовместимым контрактом нужно
разрешить явно, а не сообщать ложный pass.

Обычный UAT-релиз следует [текущему профилю](ship-work-release-profile.md).
