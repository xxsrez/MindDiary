# REVIEW-01 — Корректность и незавершённые реализации

## Шаги

1. Для назначенного участка проследить входы, выходы, ошибки и вызывающие стороны.
2. Проверить граничные значения, null/empty, TODO/FIXME, заглушки, неиспользуемые ветки, несоответствие принятому контракту.
3. Для находки описать конкретный вход и последствия, проверить достижимость пути.

## Ожидается

Просмотренные файлы отмечены; дефект отделён от гипотезы и намеренно отложенной функции. Само наличие TODO не является багом.
