# REVIEW-04 — Доступ, приватность и границы доверия

## Шаги

1. Проследить identity и authorization до первого чтения данных и каждого write.
2. Проверить URL/redirect/file path, входные схемы, scope narrowing, журналирование и выдачу ошибок.
3. Сверить пользовательский ввод, corpus и description с границами доверия.

## Ожидается

Нет необоснованного доверия клиентским ролям и идентификаторам; подозрительные пути описаны без публикации секретов и эксплуатации чужих данных.
