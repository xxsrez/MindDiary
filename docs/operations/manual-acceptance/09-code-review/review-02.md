# REVIEW-02 — Производительность и расход ресурсов

## Шаги

1. Проследить типичный и большой запрос через назначенный участок.
2. Проверить N+1, полные сканирования, повторную сериализацию/хеширование, большие buffers, отсутствие pagination/backpressure, необ bounded parallelism, удержание памяти и фоновые циклы.
3. Указать размер входа, рост работы и возможное пользовательское проявление.

## Ожидается

Есть аргументированный вывод по стоимости операций; статическая оценка не выдана за измеренный latency или утечку. Нужный замер оформлен отдельно, нагрузка не запускается.
