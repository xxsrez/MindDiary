# REVIEW-05 — Конфигурация, поставка и достоверность тестов

## Шаги

1. Просмотреть назначенные workflows, scripts, package/lock/config и тестовые helpers.
2. Проверить закрепление зависимостей, failure propagation, таймауты, cleanup, секреты, различия test/product adapters.
3. Проверить, что assertions не доказывают лишь форму receipt или собственную заглушку там, где заявлен реальный результат.

## Ожидается

Найдены либо исключены конкретные разрывы в проверенной области. Автотесты только читаются; их запуск не входит в эту карточку.
