# REVIEW-03 — Конкуренция, отмена и целостность

## Шаги

1. Проследить CAS, транзакции, idempotency и порядок побочных эффектов.
2. Проверить обрыв до/после commit, повтор, timeout, lease, cleanup и частичный отказ.
3. Проверить гонки между отзывом прав, чтением и записью.

## Ожидается

Для проверенных путей описаны гарантии или конкретные нарушения; незавершённый анализ обозначен явно. Нет утверждения о live восстановлении по чтению кода.
