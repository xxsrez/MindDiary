# IMPORT-06 — Невалидный набор и исправленная повторная попытка

Данные: два отдельных набора — с некорректным UTF-8 и с нарушенной ссылкой OKF; их валидные исправления.

## Шаги

1. По очереди выбрать каждый невалидный набор и проверить отказ.
2. После каждого отказа сверить HEAD.
3. Выбрать исправленный набор и завершить новый импорт.

## Ожидается

Невалидные данные не попадают в HEAD; отказ понятен и не оставляет UI навсегда занятым, исправленный импорт работает.
