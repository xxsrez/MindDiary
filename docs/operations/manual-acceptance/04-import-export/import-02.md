# IMPORT-02 — Замена снимка с удалением Markdown

Данные: Mind с двумя Markdown-файлами и opaque-файлом; новый валидный снимок исключает один Markdown-путь.

## Шаги

1. Проверить preview удалений; отменить первый импорт и сверить HEAD.
2. Повторить план и подтвердить замену.
3. Проверить HEAD, opaque-файл и предыдущую revision.

## Ожидается

Отмена ничего не меняет; подтверждение удаляет только ожидаемый Markdown из HEAD, сохраняет opaque и историю.
