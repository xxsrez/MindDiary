# IMPORT-07 — Превышение лимита и следующая попытка

Источник: [import/export](../../import-export-browser-uat-runbook.md). Данные: актуальный лимит файла и безопасный набор чуть выше него. Не заполнять общую квоту UAT.

## Шаги

1. Выбрать превышающий лимит набор, проверить отказ и HEAD.
2. Выбрать небольшой валидный набор и завершить импорт.

## Ожидается

Нет изменения HEAD после отказа; допустимый импорт работает. Лимит сверить с текущим контрактом, не копировать историческое 1 MiB.
