# IMPORT-04 — Сетевая ошибка при чтении статуса

Подготовка: возможность отключить сеть только у тестового браузера/вкладки, не у релизного процесса.

## Шаги

1. Во время незавершённого импорта временно отключить сеть тестового клиента.
2. Убедиться, что ошибка видна; восстановить сеть и продолжить.
3. Перечитать данные и историю.

## Ожидается

Временная ошибка не теряет указатель восстановления и не создаёт новый импорт; результат ровно один.
