# EXPORT-01 — Экспорт точной revision после дальнейшей правки

Данные: известные файлы и hashes revision A, затем изменённая revision B.

## Шаги

1. На сайте запросить export именно A.
2. Скачать и локально осмотреть архив без исполнения вложенного кода.
3. Сравнить состав и bytes с A, отдельно проверить текущую B.

## Ожидается

Архив соответствует A, не смешан с B; исходный Mind не изменён. Загрузка архива не равна проверке его содержимого.
