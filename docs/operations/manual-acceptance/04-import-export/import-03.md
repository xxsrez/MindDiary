# IMPORT-03 — Продолжение после обновления страницы

Данные: набор достаточно велик, чтобы увидеть незавершённую стадию; сохранённые путь цели и import_id.

## Шаги

1. Начать импорт и обновить страницу во время загрузки.
2. При запросе заново выбрать тот же набор и продолжить.
3. После завершения перечитать данные и историю.

## Ожидается

Продолжается прежняя сессия; нет второй копии или лишнего commit, данные полны.
