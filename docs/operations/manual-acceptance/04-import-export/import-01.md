# IMPORT-01 — Полный импорт небольшого Mind

Данные: валидный синтетический OKF-набор; перечень путей и SHA-256. Цель — отдельный тестовый Mind.

## Шаги

1. Выбрать набор через штатный web import; проверить точную цель и preview.
2. Подтвердить, дождаться результата и записать revision.
3. Через MCP перечислить и прочитать импортированные файлы; открыть Mind заново.

## Ожидается

Одна новая revision; пути и содержимое соответствуют набору. Сообщение об успехе UI подтверждено чтением.
