# Пользовательские инциденты

Затрагиваемые части: end-to-end, web, mcp, storage.
Источник ожиданий: [спецификация](../../../specs/sites-storage-capacity-import.md).
Действуют [общие правила](../defaults.md), в том числе лимит 10 минут.

Подготовка группы: заранее разрешённый тестовый principal, изолированные Minds,
контрольные данные и baseline inventory. Чтение через MCP выполняется в реально
подключённом клиенте; сценарии с несколькими ролями требуют отдельных тестовых
сессий. Нет нужного предусловия — blocked, без подмены локальными автотестами.
