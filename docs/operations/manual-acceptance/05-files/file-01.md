# FILE-01 — Вложение из разговора до сохранённых байтов

Подготовка: клиент с настоящим native file bridge, безопасный файл с известными size/hash, тестовый writable Mind.

## Шаги

1. Прикрепить файл к разговору и явно попросить сохранить только в тестовый Mind.
2. Проверить итоговую revision и ссылку на файл.
3. Получить сохранённый файл штатным способом и сравнить hash.

## Ожидается

Сохранены исходные bytes; не только имя, текстовое описание или временная ссылка. Отсутствие native bridge — блокировка этого случая, не pass по companion.
