# FILE-04 — PDF и ZIP доступны реальному клиенту

Источник: [ChatGPT host](../../../reports/2026-09-10-release-0.4-chatgpt-host-acceptance.md). Данные: синтетические PDF/ZIP с известными hashes.

## Шаги

1. В клиенте получить PDF и прочитать контрольный текст.
2. Получить ZIP, сверить hash и осмотреть состав без исполнения.
3. Отдельный одноразовый download grant повторно использовать после первого успешного чтения.

## Ожидается

Получены реальные bytes, не только descriptor; повтор одноразового grant отклонён. Истечение срока здесь не проверяется.
