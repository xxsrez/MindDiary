# FILE-03 — Замена бинарного файла и историческое чтение

Данные: две безопасные версии бинарного файла с разными hashes.

## Шаги

1. Сохранить первую версию, затем заменить второй.
2. Прочитать текущий файл и тот же путь из первой revision.

## Ожидается

Обе версии имеют исходные hashes; историческая ссылка не возвращает новые bytes.
