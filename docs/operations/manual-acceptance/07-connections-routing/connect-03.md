# CONNECT-03 — Повтор refresh после отказа выдачи

Источник: локальный аудит 2026-11-03. Нужны тестовое подключение и способ
вызвать отказ создания authorization mirror после начала refresh без выдачи
новых credentials. При отсутствии управляемой инъекции случай blocked.

## Шаги

1. Подключить тестового клиента и подтвердить чтение тестового Mind.
2. Вызвать указанный отказ при refresh; не записывать секреты в результаты.
3. После устранения отказа повторить refresh с прежним credential и проверить чтение.

## Ожидается

Повтор после отказа до выдачи новых credentials проходит, подключение не
отзывается как reuse. Успешную ротацию и потерю уже отправленного ответа этот
случай не имитирует.
