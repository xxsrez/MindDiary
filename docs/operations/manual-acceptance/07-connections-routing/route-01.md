# ROUTE-01 — Описание отсутствует: только прямая просьба

Данные: тестовый read_write Mind без description; известный HEAD.

## Шаги

1. В новом разговоре обсудить факт, который можно было бы сохранить, без указания Mind.
2. Проверить отсутствие автоматических чтений/записей.
3. Явно попросить сохранить факт в этот Mind и перечитать.

## Ожидается

Без прямого выбора Mind не используется; прямая просьба работает в пределах effective write.
