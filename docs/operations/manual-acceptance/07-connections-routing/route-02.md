# ROUTE-02 — Два совпавших Mind и ограничение «только в A»

Данные: два тестовых read_write Mind с совпадающими descriptions, каждый с собственным контрольным фактом.

## Шаги

1. Обсудить подходящий долговечный факт и проверить отдельное сохранение в оба Mind.
2. Другой факт попросить сохранить только в A.
3. Перечитать оба Mind.

## Ожидается

Первый факт есть в обоих с независимыми revisions; второй только в A. Успех первого commit не подменяет проверку второго.
