# ROUTE-05 — Частичный успех сохранения в два Mind

Подготовка: два тестовых назначения; после discovery перед вторым commit отозвать право записи только на второе через тестового Owner.

## Шаги

1. Попросить сохранить факт в оба и воспроизвести отзыв между выбором и второй записью.
2. Перечитать доступный результат и получить состояние второй операции.

## Ожидается

Успешная запись сохранена; отказ второй не скрыт за общим «готово», нет обхода доступа. Если интервал не удалось воспроизвести, это указать, не считать случай пройденным.
