# ROUTE-04 — Личное не переносится в общий Mind автоматически

Подготовка: disposable Personal Mind с синтетическим фактом; ordinary Mind с другим тестовым читателем и совпадающей темой.

## Шаги

1. Явно прочитать факт из Personal и обсудить его без просьбы переносить.
2. Перечитать ordinary Mind.
3. Дать отдельную прямую просьбу перенести факт и проверить источник.

## Ожидается

До прямой просьбы общего раскрытия нет; после разрешённого переноса сохранена точная provenance. Настоящий Personal пользователя не используется.
