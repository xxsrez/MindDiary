# Проектные решения каталога

Это решения и пояснения исполнителя, не требования владельца.
Они подчинены [Requirements](Requirements.md); этот файл не может менять их.

## Организация

- topics — короткие стабильные ключи конкретного поведения; clients используется
  только для клиентских случаев. Словарь хранится в topics.json.
- Read-only selector выдаёт объяснимых кандидатов, не заменяя impact-анализ.
  Проверка selector не является запуском продуктовых сценариев.
- Старые смешанные runbooks стали входными страницами, прежние контракты
  сохранены в legacy-acceptance для machine gates и исторической воспроизводимости.

- Ручные UAT-проверки выбираются по `uat: always | when-changed | extended`
  и условию `uat_when` согласно [правилам выбора](uat-selection.md).
  Отсутствие метки не включает карточку в релиз; автотесты остаются отдельно.

- Текущее имя «Глубокая проверка Mind Diary» предложено исполнителем.
  Отдельное явное утверждение имени владельцем пока не зафиксировано.
- Один Markdown-файл на карточку, стабильный ID и индекс каждого раздела.
- Общие значения наследуются: defaults → раздел → карточка.
- Статусы, отсутствие автоматических повторов и правила остановки описаны
  в [defaults](defaults.md).
- Общий бюджет, порции ревью и учёт покрытия файлов описаны в
  [порядке глубокой проверки](deep-review.md).
- Результаты отделены от карточек и ведутся по [правилам истории](runs/README.md).
- Для изоляции от параллельного релиза выбран отдельный Git worktree.

## Развитие и сопровождение

Требование развития базы реализуется через инструкции агенту и
[порядок сопровождения](maintenance.md). Фоновый сервис не создан.
Способ автоматизации владельцем не задавался.

При согласованном изменении требований сохранять источник нового указания.
Наполнение каталога в рамках требований не требует менять Requirements.
Правила репозитория, полномочий и безопасности действуют независимо от этого
каталога; они не приписываются владельцу как требования из данного разговора.

## Неопределённости

- Классификация влияния, метод оценки стоимости и способ измерения выбраны
  исполнителем; владелец не задавал конкретную методику.
- Для инцидента с автобусами неизвестны точные шаги и смысл операции
  «загрузить». Сообщение о сбое не устанавливает его причину.
- Запрет запуска сценариев относится к текущему созданию каталога во время
  параллельного релиза; будущий запуск определяется новым поручением.
- Наличие карточек и документации не доказывает прохождение проверок
  или полное выполнение требований.
