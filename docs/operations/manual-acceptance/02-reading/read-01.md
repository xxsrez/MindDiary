# READ-01 — Ответ по содержимому с проверяемым источником

Данные: тестовый Mind с двумя разными фактами и похожими названиями документов.

## Шаги

1. В новом разговоре явно выбрать Mind и спросить один контрольный факт.
2. Попросить указать источник; прочитать указанный файл и revision напрямую через MCP.

## Ожидается

Ответ соответствует данным, источник относится к выбранному Mind и реальной revision; похожий документ не подменяет источник.
