# READ-03 — История не смешивается с текущим состоянием

Данные: файл в revision A содержит «старое», в B — «новое»; второй файл удалён в B.

## Шаги

1. Прочитать оба файла по A, затем текущий HEAD.
2. Выполнить поиск по A и по HEAD.
3. Попросить изменить A.

## Ожидается

История возвращает старые данные, HEAD — новые и отсутствие удалённого файла; запись поверх A отклоняется, HEAD не меняется.
