# READ-02 — Полнота списка за первой страницей

Данные: тестовый Mind с числом файлов больше фактического размера страницы; известный перечень и контрольный файл в конце.

## Шаги

1. Попросить перечислить все файлы выбранного Mind, продолжая страницы до конца.
2. Найти и прочитать последний контрольный файл.
3. Сравнить перечень с исходным.

## Ожидается

Нет пропусков и дублей; первая страница не выдаётся за полный список. Фактические размер страницы и число файлов записаны в результате.
