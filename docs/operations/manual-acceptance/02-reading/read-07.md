# READ-07 — Все страницы диагностики через публичный MCP

Источник: MD-488, UAT 191 от 2026-09-21. Проверка завершена, но из 316
advisories доступны 100: сервис отдаёт next_cursor, публичная схема не принимает
cursor. Связанный инцидент: [REG-01](../08-regressions/reg-01.md).

## Шаги

1. Подготовить изолированный Mind с известными диагностическими сообщениями
   разных уровней; проверить размеры выдачи 0, 100, 101 и больше двух страниц.
2. Получить живую tools/list schema в настоящем MCP-клиенте. Вызвать
   validate_mind и передавать продолжение только через объявленный параметр.
3. Прочитать до next_cursor=null; сверить полный набор и счётчики, исключить
   пропуски, дубли и зацикливание. Отличать validation_complete от полноты выдачи.
4. Между страницами изменить HEAD тестового Mind: продолжение должно сохранить
   исходную точную ревизию и версию правил либо дать явный корректный отказ.
5. Проверить неверный cursor, cursor другой ревизии/Mind и отзыв доступа.

## Ожидается

Все сообщения доступны через опубликованный контракт. Внутренний вызов сервиса
в обход schema и первая успешная страница не закрывают баг. Тесты не должны
менять данные пользовательского Mind. Новый прогон не выполнен.
