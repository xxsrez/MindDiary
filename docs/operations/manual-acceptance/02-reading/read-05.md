# READ-05 — Файловый поиск после пустого search

Данные: контрольный факт, не найденный точным search. Источник: [файловая приёмка](../../../reports/2026-09-09-file-operations-acceptance.md).

## Шаги

1. Выбрать Mind и revision, получить пустой search.
2. Продолжить list_files → grep_files → read_files в той же revision.
3. Запросить отсутствующий путь и пройти восстановление списка.

## Ожидается

Контрольный факт найден либо честно остался неизвестен; нет догадок, смены Mind или revision.
