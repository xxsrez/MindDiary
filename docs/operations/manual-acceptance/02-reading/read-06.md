# READ-06 — Продолжение списка при изменении HEAD

Данные: файлов больше одной страницы; второй тестовый Editor.

## Шаги

1. Получить первую страницу на revision A.
2. Вторым клиентом добавить файл в HEAD.
3. Продолжить исходный список; отдельно перечитать новый HEAD.

## Ожидается

Continuation сохраняет A без пропусков и дублей; новый файл есть только в новом списке.
