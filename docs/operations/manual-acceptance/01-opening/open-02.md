# OPEN-02 — Переименование не ломает ссылку

Подготовка: тестовый ordinary Mind и сохранённая ссылка на него.

## Шаги

1. Изменить display name через сайт.
2. Повторно открыть старую ссылку и найти Mind через MCP.

## Ожидается

Новое имя видно, handle и идентичность Mind не меняются; содержимое сохранено.
