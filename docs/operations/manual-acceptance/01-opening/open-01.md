# OPEN-01 — Прямой адрес и повторное открытие

Подготовка: тестовый ordinary Mind с известным handle и контрольным содержимым.

## Шаги

1. Открыть точный адрес после входа; перейти в другой раздел и вернуться кнопкой «Назад».
2. Обновить страницу и снова открыть тот же адрес в новой вкладке.
3. Через подключённый MCP прочитать контрольный файл этого Mind.

## Ожидается

Каждое открытие разрешается в тот же Mind; management UI загружается без бесконечного ожидания, MCP возвращает ожидаемый файл. Наличие web-редактора не предполагается.
