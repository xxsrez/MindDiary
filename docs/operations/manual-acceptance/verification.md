# Проверка организации каталога — 2026-09-21

Проверены документы и read-only подборщик, не приложение и не тест-кейсы продукта.

## Подбор по ситуации

| Запрос selector | Ожидаемое ограничение |
| --- | --- |
| --topics import_resume | IMPORT-03/04 и четыре обязательные UAT-карточки; без export/OAuth |
| --topics ui_layout | UAT-05 и обязательное ядро; без file/credentials |
| --topics oauth --clients chatgpt | Общие OAuth и ChatGPT; без Codex и FILE |
| --ids REG-01 / --search автобусы | Найден конкретный инцидент |
| --mode deep | Все 72 карточки, включая REVIEW и backup |
| Ошибочный topic/ID/client или пустое совпадение | Ошибка, не успокаивающий план из одного smoke |
| Запуск из другой рабочей папки | Каталог разрешается относительно скрипта |

Эти семь проверок реализованы в
[тестах самого подборщика](../../../scripts/select-manual-checks.test.mjs).
Они не запускают UI/MCP, не обращаются к UAT, не читают пользовательские Minds.

```sh
node --test scripts/select-manual-checks.test.mjs
node scripts/select-manual-checks.mjs --validate
```

## Границы

Поиск по 42 темам и ID уменьшает чтение каталога, но не является семантическим
анализатором diff. Исполнитель обязан проверить радиус изменений и дополнить темы.
Для сложной смены storage общий выбор import_resume был бы недостаточен.
Реальная применимость и длительности карточек ещё не подтверждены прогонами.

Десять смешанных runbooks стали входными страницами, старые контракты сохранены
в legacy-acceptance. Profile, AGENTS, delivery specification и runtime reference
направляют ручной план в каталог. Автоматические suites не заменены selector.
Исходные незакоммиченные правки продукта другой сессии сохранены; requirements
перенесены без изменения содержания и ownership.
