# OPS-05 — Ограничение потокового JSON-запроса

Источник: локальный аудит 2026-11-03; ранее JSON целиком читался до проверки размера. Автоматическая регрессия: [product-http-body-limits](../../../../tests/unit/product-http-body-limits.test.mjs).

## Шаги

1. В изолированной тестовой среде с тестовым principal отправить допустимый web control JSON; убедиться, что штатная операция работает.
2. Отправить на тот же маршрут поток больше 64 KiB без `Content-Length`; заниженный заголовок проверять через тестовый transport, который допускает такую доставку. Для плана импорта повторить проверку границы 16 MiB, не создавая import.
3. Проверить отказ и отсутствие выполнения операции; убедиться, что передача останавливается после превышения лимита и следующий допустимый запрос обрабатывается.
4. Отдельно для modern и compatibility MCP отправить авторизованный потоковый JSON-RPC запрос свыше 32 MiB без достоверного `Content-Length`. Проверить HTTP 413, отсутствие вызова tool и успешный последующий допустимый запрос.

## Ожидается

Web-превышение возвращает `invalid_request`; MCP-превышение — JSON-RPC `-32600`. Ни одно не меняет данные и не требует дочитывания остального тела. Допустимое UTF-8 содержимое принимается; размер считается в байтах.
