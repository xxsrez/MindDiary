# OPS-02 — MCP transport и ошибки настоящего подключения

## Шаги

1. Зафиксировать клиент, endpoint и согласованную версию протокола.
2. Вручную пройти доступные initialize/discovery и безопасный read в реальном клиенте.
3. На тестовом подключении проверить неверный аргумент и отказ без нужного scope, затем корректный read.

## Ожидается

Transport, schemas и ошибки работают в выбранной паре клиент/endpoint. Legacy проверяется отдельной записью только если заявлена его поддержка; успех одного профиля не доказывает другой.
