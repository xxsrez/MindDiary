# OPS-06 — Сбой записи производного checkpoint при восстановлении

Источник: локальный аудит 2026-11-03. Данные: изолированная копия с валидным
snapshot и непрерывным хвостом журнала; нужна безопасная инъекция ошибки записи
checkpoint. Без неё случай blocked.

## Шаги

1. Создать тестовый Mind и изменение, затем оставить snapshot позади журнала.
2. Вызвать холодный запуск с устойчивым отказом записи нового checkpoint и прочитать тестовый Mind.
3. Восстановить запись checkpoint, повторить запуск и сверить состояние с журналом.

## Ожидается

Валидный журнал восстанавливает точное состояние даже при отказе производного
checkpoint; последующий запуск может записать checkpoint. Повреждённые данные
или разрыв журнала не обходятся.
