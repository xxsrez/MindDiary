# OPS-03 — Диагностика сбоя без утечки данных

## Шаги

1. Для безопасной ошибочной операции сохранить время и разрешённый request ID.
2. Найти относящееся к ней наблюдение в доступных логах/метриках, не выгружая сырые secrets/content.
3. Проверить понятность ошибки пользователю и возможность отличить timeout, denial и внутренний сбой.

## Ожидается

Сбой можно локализовать по связанным наблюдениям; отсутствие telemetry отмечено как ограничение. Логи не раскрывают приватное содержимое.
