# OPS-04 — Backup и восстановление изолированной копии

## Шаги

1. До запуска установить разрешённый backup/restore workflow, отдельный пустой target и возможность его очистки.
2. Для синтетических данных создать backup, изменить только тестовую копию, восстановить в разрешённую изолированную среду.
3. Сверить content, history и необходимые service metadata по принятому backup-контракту, завершить cleanup.

## Ожидается

Реальная восстановленная копия проверена. Export одного Mind не назван system backup. Нет отдельного target или полномочий — blocked, основной UAT не перезаписывается.
