# ACCESS-05 — Удаление тестового Mind

Подготовка: только run-owned ordinary Mind с несколькими revisions; записанные ссылки и исходная inventory.

## Шаги

1. Удалить Mind через owner UI с подтверждением.
2. Проверить прежний URL, HEAD, исторические ссылки и список Minds.

## Ожидается

Content и история недоступны, чужие Minds не затронуты; удалённый объект не используют для дальнейших зависимых сценариев.
