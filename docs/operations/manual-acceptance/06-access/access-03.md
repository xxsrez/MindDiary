# ACCESS-03 — Private, unlisted и public

Подготовка: только синтетический Mind; второй вошедший пользователь без membership и отдельная сессия без входа.

## Шаги

1. Owner проверяет предупреждение и переключает private → unlisted → public.
2. В каждом режиме второй пользователь проверяет точный URL, каталог и историю; сессия без входа проверяет отсутствие product data.
3. Вернуть private и повторить запросы второго пользователя.

## Ожидается

Unlisted доступен вошедшему по URL без каталога, public также через каталог; оба дают чтение истории, не запись. Private отзывает новые чтения, а anonymous не читает ни в одном режиме.
