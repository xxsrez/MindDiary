# ACCESS-02 — Отзыв доступа в открытой сессии

Подготовка: тестовый участник уже открыл private Mind и прочитал историю.

## Шаги

1. Owner удаляет участника.
2. Участник в прежней сессии пытается прочитать HEAD и старую revision, выполнить поиск и запись.

## Ожидается

Новые запросы запрещены без раскрытия данных; уже показанные клиенту данные не считаются удалёнными из его памяти.
