# UAT-01 — Короткая проверка опубликованного приложения

## Шаги

1. После подтверждения deployment открыть выбранный UAT в авторизованном Browser.
2. Проверить список Minds, /me и страницу тестового ordinary Mind, затем обновить страницу.
3. Проверить отсутствие бесконечной загрузки и безопасное отображение ошибки для недоступного адреса.

## Ожидается

Приложение отвечает, авторизованный пользователь видит свои разрешённые данные; наблюдение связано с текущей deployment. Не создавать новый account ради каждого smoke.
