# UAT-04 — Сохранность после согласованного redeploy

## Шаги

1. В изолированных данных до согласованной публикации сохранить exact revisions, hashes, roles и usage modes.
2. После запланированного deployment перечитать то же состояние через web и MCP.
3. Если требуется restart того же artifact, проводить только в выделенном окне без чужого релиза; иначе отметить эту часть blocked.

## Ожидается

Данные, история и текущие права сохранены. Обычное обновление страницы не заменяет redeploy; проверка не инициирует второй deployment без необходимости.
