# UAT-09 — Индекс после обычного commit

## Шаги

1. Обычным commit сохранить уникальный синтетический marker и exact revision.
2. Ограниченно дождаться ready той же revision, затем выполнить hit и no-hit search.
3. Сверить неизменность HEAD от индексирования и выполнить run-owned cleanup.

## Ожидается

Hit/no-hit относятся к той же revision, нет подмены другой ревизией. Lag записан; внутренние repair/corruption endpoints не используются.
