# UAT-10 — Восстановление Mind из export

## Шаги

1. Создать синтетический Mind, экспортировать exact revision, проверить состав, hash и весь OKF bundle.
2. Внести другую правку; прочитать исходную историю.
3. Через разрешённый текущий import workflow восстановить снимок как новую HEAD после preview и свежего CAS; экспортировать и сравнить.
4. Проверить неизменность исходной истории и отсутствие service metadata в переносимом архиве.

## Ожидается

Содержимое восстановлено новой revision, история не переписана. Это restore одного Mind, не системный backup. Без реализованного разрешённого restore путь blocked.
