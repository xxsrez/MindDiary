# CODEX-01 — Установленный Codex plugin и первый вызов

## Шаги

1. Сверить source, Marketplace snapshot, установленный package/version и фактический tool catalog.
2. В разрешённом изолированном контексте Codex пройти штатное подключение и открыть новый разговор.

Установленный пакет вызывает настоящий endpoint. Конфигурация, auth_status и mocks не заменяют вызов; системный браузер не открывается без разрешения.
