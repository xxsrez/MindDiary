# Интеграция с Codex

Проверять настоящий установленный plugin и прямые MCP-вызовы в Codex. Desktop и CLI фиксировать отдельно; если поддержка обоих входит в scope, результаты нужны для каждого. Наличие схемы или auth_status не доказывает рабочую интеграцию.

Действуют [общие правила](../defaults.md). Для составных карточек ссылки на другие
ID означают повторное использование шагов: каждый вложенный ID выполняется один
раз на данной комбинации версии/клиента/данных и получает отдельный результат.
Лимит 10 минут применяется к каждому такому случаю; сборка общего результата
не запускает их повторно. Общий бюджет прогона фиксируется до начала.
