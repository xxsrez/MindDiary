# CODEX-03 — Свежая сессия Codex и текущие полномочия

## Шаги

1. В тестовом аккаунте открыть новый контекст Codex после изменения mode или отзыва тестового credential.
2. Прочитать fresh discovery и выполнить разрешённый read либо проверить denial после revoke.
3. Сверить фактические права со свежим server state, а не сохранённым текстом предыдущего разговора.

## Ожидается

Новый контекст отражает текущие права. Это не compaction-тест; автоматический выбор/запись по description проверяются отдельными карточками.
