# WRITE-04 — Ошибка одного элемента атомарной записи

Данные: один корректный и один заведомо некорректный элемент changeset; записанный исходный HEAD.

## Шаги

1. Вручную отправить один changeset с обоими элементами через MCP.
2. Прочитать HEAD и путь корректного элемента.

## Ожидается

Весь changeset отклонён; корректная половина не появилась и HEAD не продвинулся.
