# WRITE-02 — Два редактора меняют одну базу

Подготовка: два тестовых Editor с доступом к одному Mind; оба прочитали один HEAD.

## Шаги

1. В двух независимых клиентских сессиях подготовить разные изменения на общей базе.
2. Сохранить первое, затем отправить второе с прежней expected_revision.
3. Перечитать HEAD; после конфликта отдельно построить второе изменение на свежей базе.

## Ожидается

Устаревшая запись не затирает первую. После осознанного разрешения конфликта обе нужные правки присутствуют.
