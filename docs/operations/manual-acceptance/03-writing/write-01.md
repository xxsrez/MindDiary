# WRITE-01 — Создание, изменение и удаление с историей

Данные: изолированный writable ordinary Mind.

## Шаги

1. Попросить сохранить новый факт только в выбранный Mind; перечитать результат.
2. Изменить факт и перечитать.
3. Удалить созданный материал из HEAD; прочитать его прежнюю revision.

## Ожидается

Каждый успешный commit имеет проверяемый результат; удаление из HEAD не стирает историю, другие Minds не изменены.
