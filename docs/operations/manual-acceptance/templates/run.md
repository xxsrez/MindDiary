# Ручная приёмка — дата и run ID

- Scope: список ID или ссылка на зафиксированный перечень.
- Версия каталога: Git SHA; для незакоммиченных карточек сохранить их снимок/diff.
- Продукт: Git SHA, deployment/version, среда.
- Клиент: название и версия; исполнитель.
- Общая подготовка: тестовые данные, baseline и затраченное время.
- Начало / завершение:

| ID | Статус | Время | Наблюдение / свидетельство |
| --- | --- | --- | --- | --- |
| CASE-ID | not-run | — | Ещё не выполнялся |

Для defect/blocked/timeout: последний шаг, ожидаемое и фактическое, условие
продолжения. Для not-applicable: основание исключения из scope.
Повтор: отдельная строка с номером попытки и причиной, прежнюю не стирать.

## Очистка и итог

Для глубокой проверки: общий бюджет и остаток; покрытие файлов ревью
(путь/диапазон, направления REVIEW, состояние, находки); отдельные итоги
DevOps/MCP, ChatGPT и Codex. Применимые исключения перечислить с основаниями.

Функциональные результаты; cleanup status и сравнение baseline hashes;
при pending — точные run-owned объекты в закрытом журнале.
Число всех выбранных случаев и каждого статуса, оставшиеся ограничения.
Не приравнивать отсутствие дефектов к отсутствию непроверенных случаев.

Расход токенов: только измеренный и с областью измерения (карточка/группа/прогон);
при отсутствии надёжной атрибуции — неизвестно. Не распределять общий расход поровну.
