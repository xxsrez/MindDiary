# CASE-ID — Название пользовательского сценария

Данные: только специфические предусловия; общие берутся из раздела.

## Шаги

1. Действие пользователя.
2. Проверка результата другим чтением, если применимо.

## Ожидается

Конкретный наблюдаемый результат и отсутствие существенного побочного эффекта.

Необязательные дополнения: лимит, особая очистка, связанные инциденты,
зависимость от другого CASE-ID. Не копировать сюда defaults.

Для UAT добавить YAML frontmatter `uat: when-changed` и конкретное
`uat_when` по [правилам выбора](../uat-selection.md).
В каждую карточку добавить `topics: ["ключ"]` из [словаря](../topics.json).
Только если случай специфичен клиенту — `clients: ["chatgpt"]` или `["codex"]`.
Не копировать широкое условие раздела в разные узкие случаи.
