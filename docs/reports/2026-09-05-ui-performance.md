# Проверка интерфейса и скорости Mind Diary UAT

Дата: 2026-09-05. Статус: исходные замеры и локальная проверка завершены;
повторные hosted-замеры выполняются после публикации. Production не затронут.

## Обход интерфейса

В реальном Chrome проверены home, My Mind, Minds, Public Minds, Invitations,
Account, Connections, карточка подключения, Advanced MCP и фильтр revoked,
Help with Codex и переключение Desktop/CLI. В форме создания Mind проверены
автоматический адрес и отмена; на ordinary Mind раскрыты export, Markdown
import, storage и invitations. Изменения прав, приглашения другим людям,
создание credentials и удаление данных не выполнялись. Content operations
проверяются отдельными существующими автоматическими сценариями, а не записью
в пользовательские Minds ради измерения скорости.

## Обнаруженные причины и изменения

1. `/minds` одновременно загружал список и настройки Codex, хотя настройки
   находились в закрытом `details`. Теперь запрос настроек начинается при
   первом раскрытии. Уже видимые панели `/me` и ordinary Mind сохраняют
   немедленную загрузку. Прямой fragment-link раскрывает настройки; повторное
   раскрытие не дублирует запрос, ошибки сохраняют прежний retry.
2. HTML подключал versioned CSS tokens, а shell CSS повторно импортировал их
   без версии. Удалён второй импорт: документ остаётся единственным местом
   подключения. Это также устраняет смешивание версионированного и старого
   кэшированного файла.

Серверная обработка истечения приглашений изучена: adapter уже не добавляет
canonical event при пустом результате. Изменять её только на основании
единичной задержки было бы недостаточно обоснованно; она оставлена прежней.
Авторизация, API, persistent cache и инфраструктурные лимиты не изменены.

## Исходная серия UAT

Исходная версия Sites: `117`, source mirror
`f45534a21694ef4f1f50b8dd057ba856f104478c`, монорепозиторий
`51c1b78e28659b189cea8d8fff07bd19666e404c`.

обычный browser cache, без искусственного ограничения сети. Между группами
по пять наблюдений были паузы на работу с кодом. Все samples, включая выбросы,

## Сбой встроенного браузера

Контрольный сайт, пустая вкладка, SVG с UAT и localhost Mind Diary открылись.
Навигация на UAT `/` и `/minds` в нескольких свежих встроенных вкладках
завершалась timeout `Page.navigate`, последующие команды — timeout
`Emulation.setFocusEmulationEnabled`. Отключение JavaScript в отдельной
диагностической вкладке не устранило сбой. Chrome открыл authenticated UI.
Локальная диагностика Codex не обнаружила перегрузки или нехватки памяти.

Это подтверждённый сбой взаимодействия встроенного браузера с hosted-страницей,
но не доказанный дефект JavaScript Mind Diary или недоступность сервера.
Точная причина и исправление браузера остаются открытыми; обход через Chrome
не объявляется ремонтом. Настройки доступа и защиты не ослаблялись.

## Локальная проверка

Изменение `7c0f9ff18421ad656e17e0e41c274aac899c5b36`: `npm ci`, полный
`npm run check` — 1118 Node tests и 64 browser tests прошли. Первая попытка
выявила устаревшее ожидание `@import` в тестовом сервере; оно заменено проверкой
доступности canonical tokens, а реальный browser test проверяет единственную
загрузку CSS tokens. Повторный полный gate прошёл. Отдельный vinext build и
проверка exact candidate artifact прошли. Локальный dev уже работал на
`http://localhost:3000`; его anonymous page проверена во встроенном браузере.
Существующий пользовательский dev process не перезапускался.
