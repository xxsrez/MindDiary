Система не сломана. Она запуталась.

В Mind Diary уже есть важная серверная логика, безопасность, OAuth, MCP и UAT. Но пользовательский путь, developer-инструменты, операторские проверки и будущие file/scale-функции оказались свалены в одну страницу и один release. Из-за этого продукт выглядит сложнее, чем он есть, а релиз не умеет закончиться.

Показать диагноз ↓

Наша цель: оставить обычному человеку три понятных шага, спрятать технический шум в Advanced и довести один маленький MVP до честно проверенного Done.

Важно

Это не заявление, что новый интерфейс уже сделан. Это карта текущего состояния, целевой модели, blockers и порядка работы.

Fresh read после reconciliation 2026-08-24: Project 215, Release 140, unfinished 21, Backlog 0. Девятнадцать post-MVP Tasks сохранены вне Release. Live-статусы могут измениться и принадлежат Task Manager. Архитектурные решения до принятия остаются proposal.

Главная мысль: пользовательский UI не должен повторять внутреннюю архитектуру. Security invariants остаются на сервере, а интерфейс переводит их в человеческие ответы.

Что уже правильно и сохраняется

  • Одна credential может читать 0..N Minds.
  • У неё может быть не больше одного writable Mind.
  • Write использует текущие write_binding_id и binding version.
  • Revoke, stale binding и rebind работают fail closed.
  • ACL, scopes, actor identity и CAS проверяются сервером.

Что нельзя переносить в пользовательскую модель

  • Raw grant IDs и token IDs в адресах и copy.
  • Protocol versions и endpoints в onboarding.
  • 37 раскрытых binding editors на одной странице.
  • Automatic capture рядом с обычным доступом.
  • Operator playbooks внутри ordinary settings.

08 · Риски и блокеры

Большинство «блокеров» — наша внутренняя работа.

Acceptance выполняет agent. Пользователь подключается только на точной secret/security или authority boundary; после одного действия agent автоматически продолжает с остановленной точки.

Внутренний gate

Можно решить кодом, docs, тестом, fixture, Task Manager mutation или UAT action.

Не перекладываем на человека.

Потенциальный внешний blocker

Появляется только после самостоятельной попытки и доказательства, что retry/fix/reconcile не помогают.

Один actor, одно действие, один resume signal.

Non-blocking scope

BundleFile, Brain scale и universal ingress полезны, но их отсутствие не меняет terminal status MVP 0.1.

Сохраняем, но переносим.

Кто что делает при приёмке

Agent-owned

Tests, Browser/Computer Use, Marketplace refresh/install, ordinary OAuth, canaries, cleanup, receipts и Done transition.

Confirmation → agent

Перед persistent UAT audience/operator allowlist или material OAuth expansion пользователь подтверждает exact diff; mutation/read-back делает agent.

Human-only security

Password, MFA, passkey, OS security prompt или создание отсутствующей external identity. После success signal agent продолжает.

Product decision

Production, новая privacy/access policy или изменение claim, если host не поддерживает incremental consent.

10 · Ревью решения

Что нужно подтвердить перед началом UI implementation.

Отметки сохраняются только в вашем браузере и не меняют проект или Task Manager. Это личный checklist для просмотра презентации.

Просмотрено 0 из 8 решений.

Definition of Done Release 0.1

  • Три понятных шага ordinary setup.
  • Один exact Git SHA, Sites deployment и plugin package.
  • Fresh Codex видит skill и ожидаемый tool catalog.
  • Read-only OAuth, write step-up и singleton writable Mind.
  • Three-principal isolation и immediate revoke.
  • Read/search/write/history/export на небольшом Mind.
  • Desktop/mobile/keyboard/browser evidence.
  • Все остальные tasks явно принадлежат post-MVP.

Чем Done не является

  • «Код вроде написан» без exact candidate.
  • HTTP regex вместо реального browser DOM.
  • Один успешный UI screen без MCP enforcement.
  • Локальный test вместо hosted evidence.
  • Старый UAT deployment вместо current artifact.
  • Manual просьба пользователю без blocker-report.
  • Закрытый Epic при незакрытых прямых dependencies.
  • Production claim: production вне этого release.
