# CloudBrain

CloudBrain — проект совместных облачных `KnowledgeSpace`, которые пользователи
и агенты подключают через MCP, читают и пополняют с сохранением переносимого
Open Knowledge Format (OKF). Каждый Space получает стабильный URL: переход по
человекочитаемому `/{space_handle}` открывает базовое либо персонализированное
представление выбранной revision, а затем позволяет обсуждать её с адаптивным
проводником. Для персонализации может использоваться ограниченный контекст из
private Personal Space пользователя; каноническое знание при этом не меняется.
Выбранную ревизию Space можно будет явно публиковать как интерактивный knowledge
site.
Практическая цель проекта — пройти путь от локального vertical slice и раннего
web-прототипа до production-подобной архитектуры в AWS.

Сейчас репозиторий содержит проверенный design bootstrap. Исполняемый MCP
server, UI и облачная инфраструктура ещё не реализованы.

Важная оговорка: подключённая MCP-база не находится целиком в контексте модели.
Она виртуально доступна через поиск и точечное чтение, а в контекст попадают
только выбранные результаты.

## Статус

Ближайший следующий этап — реализовать локальный read-only vertical slice:
импорт OKF bundle, строгую валидацию, стабильный auth-gated Space URL,
base/personalized landing, `search`/`fetch` и Streamable HTTP MCP на одном
тестовом наборе данных. До этого момента в репозитории нет команды запуска,
которую можно честно назвать рабочей.
